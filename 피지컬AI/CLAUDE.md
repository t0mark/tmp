# 피지컬AI — 말로 설명하면 그림으로

이 폴더에서는 사용자가 채팅으로 개념·구조·로봇 셋업·파이프라인·수식 흐름 등을 **대충** 설명하면, Claude가 바로 그림으로 만들어 저장한다.

## 작업 규칙

1. **되묻지 말고 먼저 그린다.** 설명이 모호해도 합리적으로 해석해서 초안을 만들고, 가정한 부분은 답변에서 한 줄로 알려준다. 수정은 사용자가 말하면 그때 반영.
2. **파일 위치/이름**: `figs/YYYYMMDD_짧은-영문-슬러그.html` (예: `figs/20261125_vla-pipeline.html`).
   - 같은 그림을 고칠 때는 같은 파일을 수정한다. 새 그림일 때만 새 파일.
3. **시작점**: `figs/_template.html`을 복사해서 `<title>`, 제목, 캡션, 본문만 바꾼다. 외부 의존성 없이 브라우저에서 바로 열려야 한다(파이썬/matplotlib 없음).
4. **그리는 방식 선택**
   - 박스·화살표 구조도, 시스템 아키텍처, 로봇/센서 배치 → **인라인 SVG** (기본). 템플릿의 CSS 클래스(`.box`, `.box.accent`, `.edge`, `.label` 등)와 화살표 마커 `url(#arrow)` 사용.
   - 아주 빠른 순서도/시퀀스/상태도 → **Mermaid** (템플릿 하단 주석 참고, CDN `mermaid@10.9.1`).
   - 수치 그래프(곡선, 막대) → 인라인 SVG로 직접 그리거나 Chart.js(`cdn.jsdelivr.net/npm/chart.js@4.4.1`).
   - 시뮬레이션/움직임(팔 관절, 궤적, 제어 루프) → `<canvas>` + 짧은 JS 애니메이션.
5. **등록**: 새 그림을 만들면 `figs/manifest.js` 배열 **맨 앞**에 항목을 추가한다 → `index.html` 갤러리에 자동 표시.
   ```js
   { file: "20261125_vla-pipeline.html", title: "VLA 파이프라인", desc: "한 줄 설명", date: "2026-11-25" },
   ```
6. **열기**: 만든 뒤 `xdg-open figs/<파일>.html` 로 열어준다 (사용자가 원치 않으면 생략).
7. **스타일**: 텍스트는 한국어, 용어는 영어 병기 OK. 색은 템플릿 토큰만 사용(라이트/다크 자동 대응). 강조는 `accent` 하나만, 남발하지 않는다.
8. 답변은 짧게: 만든 파일 경로 + 가정한 점 + "바꿀 거 있으면 말해줘" 정도.
